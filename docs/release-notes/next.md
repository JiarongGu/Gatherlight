### 更新 Claude CLI 时,文件被暂时占用也能装上

应用自己安装的 Claude CLI 在「资源 · Resources」里更新时,新文件要放到旧文件的位置上。如果这时恰好有别的程序
在读这个文件(比如杀毒软件在扫描刚下载好的程序),以前更新会直接失败,只显示「下载失败:The process cannot
access the file because it is being used by another process.」—— 而 1.3.0 的说明里写的是,更新 Claude CLI 时
不会再因为「正在使用」而失败。现在遇到这种情况,应用会等几秒再试;一直被占着的话,这次更新不装,并用中文说明
原因:

- 已安装的版本还在原处时:说明这次没能替换,**已安装的版本不受影响**,稍后再点「更新」。
- 如果旧版本已经挪开、却没能放回:如实说明现在暂时用不了,稍后再点「更新」或**重启应用**,都会先把旧版本放回去 ——
  哪怕那次下载本身失败了,也会先放回。
- 第一次安装、还没有旧版本时:只说这次没能装上,稍后再试,不会说「旧版本」怎样。

### 导出/导入「记忆」时,不再带上「判断」的模型

「判断」用哪个模型,是和它用哪个后端(Claude CLI 或本机模型)一起保存在设置里的;而导出的「记忆」文件不带
这份设置。以前导出文件仍会带上「判断」的模型名,导入到另一台安装时,那边可能拿一个本机模型的名字去问 Claude ——
Claude 不认识它,主题标注和检索时的判断就悄悄地都没有了。现在「记忆」文件只带「校准 · Cortex」里能设置的模型;
旧版本导出的文件即使带着这一项,导入时也会跳过。

**从整机备份恢复时**,备份里有这份设置,会整份恢复;应用同时会清掉当前安装里残留的「判断」模型记录,重启后以
恢复的设置为准。

### 本机模型的文件不见了,「判断」和「语义」会退回并提示

如果「判断」或「语义」绑定的本机模型文件被删掉了,而模型目录里还有别的同类模型,以前应用仍当作这一层已经配好:
「判断」每次检索都悄悄地没有意见,「语义」绑着一个不存在的模型。现在启动时会发现这一点:

- 「判断」退回 Claude CLI。启动提示会写明是哪个模型不在了、退回后**要消耗账号额度、事实内容会发给 Claude**;
  如果 Claude CLI 还没登录或没有安装,也会说明这时既不标注也不核对,以及怎么处理。
- 「语义」这次启动不生效。把模型放回后,请重启服务,再在「记忆检索」**重建一次语义索引** —— 这期间写入的事实
  没有向量,需要重建才能被按意思找到。

### 「资源」里启动 llama.cpp 时,只载入本应用的模型

llama.cpp 会列出这台电脑上别的程序缓存的模型。以前「资源」里点启动时,应用会把它列出的模型全部预先载入,
包括那些与本应用无关的模型,白占显存。现在只预先载入本应用模型目录里的模型。

还没有改的一点:如果本应用目录里的模型比 llama.cpp 同时能载入的(两个)还多,点启动时仍可能把正在用的那个挤出去。

### 本机 llama.cpp 的重启更稳妥

- **「判断」在用本机对话模型时,不会为了载入新模型自动重启 llama.cpp。** 重启的那几秒里写入的事实会永久没有
  主题标注(实测:重启窗口里写入的 5 条中有 1–2 条没有标注)。这时应用会请你重启服务,新模型会随 llama.cpp
  一起载入 —— **重启后在「记忆检索」里再选一次这个模型**,这次的选择没有保存。
  关掉「判断」时,或「判断」用的是重排模型时,仍会自动重启;但「语义」也在用这个 llama.cpp、「判断」设置了
  本机对话模型、或「语义」设置了本机模型却还没生效(要重启服务才会用上),或者这个 llama.cpp 不是本应用启动的时候,同样不会自动重启,
  而是告诉你该怎么做。
- **llama.cpp 一次回应得慢,不会再让操作报内部错误。** 以前在「资源」或「记忆检索」里的操作可能因此直接失败;
  在重启的那一刻遇到,甚至会让 llama.cpp 停在「没有运行」的状态,没有任何说明。现在重启时会先等旧进程让出
  端口再启动新的;万一旧进程一直不放,会如实告诉你 llama.cpp 现在没有运行,以及怎么处理。
- **llama.cpp 用的端口被一个不像 llama.cpp 那样回应的进程占着时,应用会直接告诉你是哪个端口**,请你在任务管理器
  里结束那个进程,而不是在旁边再启动一个 llama.cpp,最后只报一句「没能启动」。

### 判断时只看事实内容

开着「判断」时,判断一条检索结果有没有回答问题,现在只看这条事实的内容,不再同时附上它的主题。用 Claude CLI
判断时,在 240 题的测试集上两种方式的效果测不出差别,而送去判断的文字少了约四分之一。用本机对话模型判断时也是
这样,但这一种没有单独测过。
