### 记忆检索:三层各自叫自己在做的事

**校准 · Cortex → 记忆检索** 里的三层,原来第二层叫 **Claude CLI 增强** —— 可它自己就带着一个把这份工作
交给本机模型的开关,一旦切过去,标题上写的那个后端根本没参与。更别扭的是,那个「本机模型」选项就在
一张叫「本地模型 · Local model」的卡片上方:两个几乎同义的词,一上一下,指的却是两回事。

现在三层都按**做什么**命名,后端变成标签:

| | 做什么 | 跑在哪 |
|---|---|---|
| **公式 · Formula** | 图谱衰减 + 排名融合 + 全文检索 | 始终启用,不需要设置 |
| **判断 · Judgement** | 写入时标注主题,检索时判断哪些结果真正回答了问题 | Claude CLI **或**本机对话模型 |
| **语义 · Semantic** | 为事实生成向量,换个说法也能找到 | 本机 Ollama 嵌入模型 |

标签报的是**正在跑**的那个,不是刚存下的那个 —— 换后端要重启,中间这段时间两者并不一致,顶上会出现
「设置已保存,重启后生效」。以前换判断的后端不会提示重启,现在会。

### 「本机模型」按钮不再无缘无故点不动

判断要用本机模型时,可选的是哪些模型,以前是拿 app 自带的嵌入模型清单反推的 —— 不在清单里就当成对话
模型。这在两个方向上都是错的:

- 如果你装的本机模型**恰好都在那份清单里**,可选项就是空的,「本机模型」按钮直接变灰,而同一个面板下面
  的「本机模型占用」还列着它们 —— 有模型,却切不过去,页面上也没有一句话解释。
- 反过来,一个清单没收录的嵌入模型会被当成对话模型放出来,选中后也拦不住 —— 而标注和核对失败时是
  **不报错**的,结果只是检索悄悄地一直没变好。

现在直接问 Ollama 每个模型能做什么(它本来就会说),按这个筛。清单只在旧版 Ollama 不给这个信息时兜底。
可选项为空时,面板会说清楚是哪种情况:没装 Ollama、装了没运行、还是本机只有嵌入模型 —— 三种情况三个
不同的解决办法。「本机模型占用」里每个模型也标了「嵌入」还是「对话」。

### 下载模型有进度条了

以前点「下载」,按钮写着「下载中…」,然后就没有别的了 —— 一个几百 MB 到几 GB 的下载,期间没有进度、
没有字节数,和卡死看不出区别;而且整个下载是挂在那一次请求上的,浏览器等不下去先放弃的话,已经在下的
模型会被报成失败。

现在下载在后台跑,面板上是一条真正的进度条(整个下载合起来算,不是一层一层地重来),带 Ollama 自己的
状态说明。失败会留在原地写明原因,而不是悄悄消失。

### 「使用」不再是一个默默变灰的按钮

启用一个嵌入模型时,app 会先让它真的算一次向量 —— 算不出来就不保存,免得检索静悄悄地空掉。这一步在
模型第一次载入内存时可能要几十秒,而按钮除了变灰什么都没说。现在它会写「启用中…」,并说明正在等的是
什么。另外,如果 Ollama 已经说了某个模型不能生成向量,现在会立刻拒绝,不用先干等它载入完。
