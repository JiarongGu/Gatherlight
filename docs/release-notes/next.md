## 这一版的重点

- **后台那些单次的 Claude 调用也收紧了。** 「判断」给事实打标签、核对检索结果,自动评分,「语义」补写说法——这些都是应用在
  后台单独启动的一次 Claude CLI 调用。以前它们带着 Claude CLI 默认的命令行工具(Bash、PowerShell),而且从系统公用的临时文件
  夹启动:别的程序在那里放一个 Claude 设置文件,这些调用就会读到。现在它们没有命令行,只从应用自己的临时文件夹启动、不读任
  何文件夹里的设置,并且和规划助手一样带着应用自己的设置(不用 API 密钥和 `apiKeyHelper`,不执行技能里内嵌的命令)。提取上
  传文件的内容、合并知识库模板这两件事也改为从应用自己的临时文件夹启动。
- 记忆检索底下的库(Lyntai)从 3.5.1 升到 3.5.2。
