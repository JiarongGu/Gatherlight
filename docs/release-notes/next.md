### Memory search settings live in 校准 · Cortex

The three switches that decide how the assistant searches its memory — **公式 · Formula**, **Claude CLI
增强**, and **本地模型** — are in the **校准 · Cortex** panel, alongside the models each part of the
assistant uses. There is no separate 记忆 tab; the 1.1.2 note described one, and this is where those
controls actually are.

It reads better there anyway: the model the Claude CLI enrichment uses is a row in the same panel, so the
switch and the model it drives sit together instead of in two places. Turning the enrichment off still
takes effect immediately, with no restart.

The only memory-related item left in **资源 · Resources** is the Ollama download itself, which belongs
there with the other large files fetched onto your computer.
